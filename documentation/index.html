Nova Store — Telegram Mini App Store Kit

A complete, config-first e-commerce storefront + admin dashboard for Telegram Mini Apps, built with Next.js 15 (App Router), React 19, TypeScript and Tailwind CSS — a fully typed, component-based storefront + admin for Telegram Mini Apps. Thank you for your purchase!

77 routes Storefront + Admin TypeScript · strict Tailwind CSS Dark & Light 3 languages (RTL) Stars · TON · Stripe

Almost everything you'll change lives in one file — src/config.ts — so you rarely touch page code. The whole app is typed end-to-end and npm run build passes with zero errors out of the box.

Configuration

Open src/config.ts — one typed object (see src/lib/types.ts for the shape).

BlockWhat it controls
brandName, short name, tagline, logo emoji/SVG, author, support URL.
themecolorScheme (auto/light/dark), allowUserToggle, accent, radius, font.
currencyCode, symbol, position, decimals, separators — used by formatPrice.
commerceTax rate, flat shipping, free-shipping threshold, max qty, promo codes.
featuresToggle whole areas on/off (search, wishlist, reviews, promo, admin…).
paymentsmethods + providers (Stars/TON/Stripe) + demoSimulate.

datasource: 'mock' | 'api', apiBaseUrl, persistNamespace.
telegramWebApp behaviour: enabled, expand, haptics, closing confirmation.

Theming & dark mode

Design tokens live in app/globals.css: light values on :root, dark on :root[data-theme="light"]. Tailwind colours (in tailwind.config.ts) reference these variables, so the Black/White toggle just swaps one attribute.

/* app/globals.css */
:root[data-theme="light"]{
  --accent:#5B6CFF;   /* your brand colour */
  --bg:#1A1A1A;
  --card:#2C2C2E;
  --text:#F2F2F7;
}
/* Tailwind: text-accent, bg-card, border-border … all resolve to these vars */
Two ways to rebrandFastest: set config.theme.accent to your hex. Full control: edit the tokens in globals.css. The per-page look comes from the real Nova stylesheets in styles/.

Localization

1

Copy a locale file

Duplicate src/lib/locales/en.ts to xx.ts and translate the values.

2

Register it

Import it in src/lib/i18n.ts and add its code to config.locale.available.

3

Right-to-left?

Add the code to config.locale.rtlLocales — layout direction mirrors automatically (Arabic ships as a working example).

Products & catalog

The bundled catalog lives in src/data/catalog.ts (typed Product[] + categories). Products render generated SVG placeholders from an emoji + colour, so the demo is fully self-contained and resale-safe. Add an image field to use your own artwork.

First-visit demo datasrc/data/demo.ts seeds a couple of orders, a wishlist and an address once (guarded), so Orders/Downloads/Returns aren't empty on a fresh install. Delete those arrays to ship an empty store.

Payments

Checkout flows through one guarded adapter — src/lib/payments.ts — driven by config.payments. Three real rails plus Cash on Delivery:

RailHow it worksYou provide
Telegram StarsYour bot backend creates an invoice link (Bot API createInvoiceLink, currency XTR); the app opens it with WebApp.openInvoice().providers.telegramStars.createInvoiceUrl
TON ConnectPay on-chain from any TON wallet via the TON Connect UI SDK.manifestUrl + recipientAddress
StripeHosted Checkout Session or Payment Link (redirect; no card data touches the app).mode + checkoutUrl or paymentLinkUrl
Cash on DeliveryRecords a pending order — no gateway needed.Nothing.
Works out of the boxLeave a rail's fields blank and, with payments.demoSimulate:true, it resolves a simulated success so checkout always completes. Only publishable values/endpoints live in the client — keep secret keys and bot tokens on your server.

Admin panel

The app/admin/ folder is a full merchant dashboard with its own dark-only layout and a slide-up section drawer: dashboard, orders, order detail, products (CSV export), inventory, categories, customers, discounts, reviews, marketing, payouts, analytics, integrations and settings. Reach it from Profile → Admin Panel or /admin.

Demo dataAdmin figures merge the shopper's real orders with seeded demo history. Point the data layer at your backend for live, shared numbers.

Build & deploy

1

Build

npm run build
npm run start        # serves on port 8001
2

Host it (two options)

Node host (Vercel, a VPS, etc.): deploy the Next.js app directly.
Static host (cPanel, any HTTPS bucket): uncomment output: 'export' in next.config.mjs, run npm run build, and upload the out/ folder.

HTTPS is mandatoryTelegram refuses to load Mini Apps over plain HTTP. Enable SSL (most hosts include free Let's Encrypt) before registering the app.

Telegram setup

1

Create a bot

In @BotFather send /newbot and follow the prompts.

2

Register the Mini App

Use /newapp (or Bot Settings → Menu Button / Web App) and paste your HTTPS URL.

3

Open & test

Launch the bot and tap the menu button — your store opens as a native Mini App with themed colours, haptics and the back button wired.

Connect a backend

State goes through the store (src/lib/store.tsx) and the payments adapter. To use your own backend, set config.data.source = 'api' and apiBaseUrl, then replace the read helpers in the store with fetch() calls to your API. Keep the shape the same — every consumer already relies on it.

Troubleshooting & FAQ

A hydration warning mentions a browser extension attribute

Extensions that inject attributes into <body> can trigger a false hydration warning. The layout already sets suppressHydrationWarning; confirm by testing in an incognito window.

The dev server won't start / port is busy

Change the port in package.json (the -p 8001 flag on dev/start).

Payments just show a "demo" success

Expected until you configure a rail. Fill in the provider fields in config.payments (and add a backend endpoint where noted).

Non-English text doesn't match on first paint

The saved locale lives in localStorage, which the server can't read, so a non-default language can briefly differ before hydration. English (the default) is unaffected. For a hard requirement, read the locale from a cookie on the server.

How do I add a page?

Create a folder under app/ with a page.tsx (App Router), reuse the shared components, and link to it from a tab or button.
